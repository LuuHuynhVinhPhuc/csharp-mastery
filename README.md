# C# & .NET Mastery

Self-study reference docs for C# and .NET — split into two tracks by skill level. **Content is written in Vietnamese** (each chapter leads with a concrete example before explaining the mechanism underneath). This file is just the overview; each track has its own detailed index.

```
CSharp-Mastery/
├── README.md       ← you are here
├── Co-Ban/          ← for people new to C#
└── Nang-Cao/        ← for people who already code, want to understand the internals
```

## [Co-Ban/](Co-Ban/00-README.md) — For beginners

The **core topics** needed to start writing correct C# code: variables/data types, control flow, functions, arrays/collections, basic OOP, exception handling, intro to async and LINQ. 8 files, meant to be read in order.

## [Nang-Cao/](Nang-Cao/00-README.md) — For going deep

For people who **already know how to code** but want to understand the internals: memory/runtime mechanics, advanced OOP, SOLID, Clean Architecture, Entity Framework, Microservices, Design Patterns, Testing, SignalR, Security, Tooling. 13 files.

## Format used throughout both tracks

- 🧠 **Example first** — a concrete scenario before any explanation.
- 📌 **Why / How it works** — the mechanism underneath (what the compiler/runtime actually does).
- ⚠️ **Common pitfalls** — mistakes people typically make.
- ✅ **When to use / Key takeaway** — the practical rule of thumb.

Not sure where to start → go to [Co-Ban/00-README.md](Co-Ban/00-README.md) first.
